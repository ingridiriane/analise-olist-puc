# Análise de Dados — E-Commerce Olist

Projeto de análise exploratória desenvolvido para avaliar dados de vendas do marketplace brasileiro Olist. O objetivo é entender o comportamento dos clientes, padrões de compra, logística de entrega e fatores que influenciam na avaliação dos pedidos.

## O que foi analisado

- Desempenho e prazos de entrega (impacto de atrasos na nota dada pelo cliente)
- Distribuição regional de vendas e concentração geográfica
- Formas de pagamento mais utilizadas e volume de parcelamento
- Principais categorias de produtos em volume de pedidos e receita

## Tecnologias utilizadas

- Python
- Pandas e NumPy
- Matplotlib e Seaborn
- Visual Studio Code
